# Pradeep Venkatachalam — Portfolio

React 19 + Vite portfolio styled as a REST API console. All content comes from
`src/data/portfolio.js` (sourced from the resume) — edit copy there.

```bash
npm install
npm run dev      # local dev server
npm run lint
npm run build    # production build to dist/
```

- `src/components/Sections.jsx` — Navbar, Hero, About, Skills, Projects, Deployment, Experience, Achievements, Education, Contact, Footer
- `src/App.css` — layout and component styles; `src/index.css` — tokens, reset
- `public/` — `profile.jpg`, `Pradeep_Venkatachalam_Resume.pdf`, favicon
